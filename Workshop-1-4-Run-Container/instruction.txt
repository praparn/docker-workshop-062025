1. Interactive RUST
	1.1 run docker on interactive mode with command (Remark: For windows. Please make all command with the same line)

	docker container run  -i -t --rm --name rustweb -p 5000:5000 labdocker/alpinewebrust:latest

	1.2 open browser with url: http://<Public IP>:5000

	1.3 open another session and press command: "docker container ls"
	*Result: 
	-----------------------------------------------------------------
CONTAINER ID   IMAGE                            COMMAND                  CREATED         STATUS         PORTS                                         NAMES
abebe75c54c6   labdocker/alpinewebrust:latest   "/usr/local/bin/rust…"   6 seconds ago   Up 6 seconds   0.0.0.0:5000->5000/tcp, [::]:5000->5000/tcp   rustweb
	-----------------------------------------------------------------

	1.4 Terminate container with command: "docker container stop rustweb"
	1.5 With option "--rm" so it will remove all container after finished work

2. N-8-N Automation AI:	

	2.1 run docker on interactive mode with command:
		docker volume create n8n_data
		docker run -it --rm --name n8n -p 5678:5678 -e N8N_SECURE_COOKIE=false -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
	
	2.2 open browser with url: https://<public ip>:5678

	2.3 stop container n8n by (Ctrl+C) and run command below:
		docker volume remove n8n_data


3. Detach NODEJS
	3.1 run docker on detach mode with command
	docker container run -d -t --name rustweb -p 5000:5000 labdocker/alpinewebrust:latest

	3.2 open browser with url: http://<Public IP>:5000

	3.3 access shell to container with command: "docker container exec -i -t rustweb sh"

	3.4 test create some file with command: "touch test.rs" and "exit"

	3.5 With command: "docker container ls"
	*Result:
	-----------------------------------------------------------------
CONTAINER ID        IMAGE                        COMMAND             CREATED             STATUS              PORTS                    NAMES
e0790d46c800        labdocker/alpineweb:latest   "node hello.js"     6 seconds ago       Up 5 seconds        0.0.0.0:3000->3000/tcp   nodejs
	-----------------------------------------------------------------

	3.6 Check difference of container from original image by command: "docker container diff rustweb"
	3.7 Check process inside container by top and stats command: "docker container top rustweb","docker container stats rustweb" and "Ctrl+C"
	3.8 Check mapping port of container by command: "docker container port rustweb"
	3.9 Rename container name from "rustweb" to "rustwebnew" by command "docker container rename rustweb rustwebnew"
	3.10 Try stop/start docker with command: "docker container stop rustwebnew","docker container ls -a","docker container start rustwebnew"
	3.11 After finished to stop container. We will remove docker container with command: "docker container stop rustwebnew && docker container rm rustwebnew"

4. Detach PYTHON
	4.1 Create docker on detach mode with command
	docker container create -t --name python -p 5000:5000 labdocker/cluster:webservicelite

	4.2 Check container exist and run container with command:
	docker container ls -a
	docker container start python

	4.3 Open browser with url: http://<Public IP>:5000

	4.4 access shell to container with command: "docker container exec -i -t python sh"

	4.5 Stop container and cleanup by command:
	docker container stop python
	docker container rm python
