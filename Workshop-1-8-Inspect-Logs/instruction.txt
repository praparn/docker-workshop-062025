For this workshop. We will demonstration how to check log / configuration of container running
=============================================================================================
Part 1: Setup daemon.json for log rotate on docker daemon
1. Verify daemon.json from /etc/docker by command:
more /etc/docker/daemon.json 

2. Check log daemon by command:
docker info

=============================================================================================
Part 2: 
1. Create container nginx with command:
docker container run -dt --name rustweb -p 5000:5000 \
--log-driver json-file \
--log-opt max-size=10m \
--log-opt max-file=10 \
labdocker/alpinewebrust:latest

2. Check configuration of container with command: "docker container inspect rustweb |more"
3. Check log of container with command: "docker container logs rustweb"
4. Clean up lab:
	docker container stop rustweb
	docker container rm rustweb
